## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`.
3. Buka Settings → Pages.
4. Source: Deploy from a branch.
5. Pilih branch `main` dan folder `/root`.
6. Save, lalu buka alamat GitHub Pages yang diberikan GitHub.

## Catatan
Harga, minimal peserta, maksimal peserta, dan opsi dokumentasi sudah dimasukkan ke JavaScript sehingga total berubah otomatis saat pilihan form berubah.
